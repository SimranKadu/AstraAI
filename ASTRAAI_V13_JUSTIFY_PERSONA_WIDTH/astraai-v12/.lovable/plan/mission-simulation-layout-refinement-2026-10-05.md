# Mission Simulation Layout Refinement

## Goal
Make the mission simulation easier to scan and visually balanced without changing its calculations or controls.

## Changes
- Give the flight visualization more space and place configuration and risk information in a cleaner supporting column.
- Rebuild the altitude, velocity, acceleration, and distance readouts as consistent instrument-style metrics with units, progress indicators, and stable sizing.
- Improve spacing, headings, and mobile stacking so values remain readable at narrow widths.
- Preserve the existing launch animation, timeline, provenance, analysis, and simulation behavior.
