# AI Persona portraits

The AI Personas feature uses portrait images hosted by Wikimedia Commons so the six portraits can display when the project is run locally in VS Code. Internet access is required for these hosted images.

For fully offline/local portraits, save image files here using these exact names; the app checks local files first:

- `vikram.jpg` — Dr. Vikram Sarabhai
- `kalam.jpg` — Dr. A. P. J. Abdul Kalam
- `kalpana.jpg` — Dr. Kalpana Chawla
- `rakesh.jpg` — Dr. Rakesh Sharma
- `satish.jpg` — Prof. Satish Dhawan
- `sunita.jpg` — Sunita Williams

The portrait credits and source links are displayed on the persona cards. Please retain those attributions when reusing the images.
