🚀 AstraAI



Intelligent ISRO Research \& Learning Assistant



Explore Space. Discover Knowledge. Learn with AI.



AstraAI is an AI-powered research and learning platform focused on the Indian Space Research Organisation (ISRO). It brings together intelligent assistance, space-mission exploration, interactive simulations, AI-generated diagrams, and educational resources in one platform.



Designed to make complex space-related information easier to explore and understand, AstraAI creates an interactive learning experience for students, space enthusiasts, and curious learners.



\---



✨ Key Features



🤖 AI Assistant



An intelligent assistant that helps users explore ISRO, space missions, satellites, launch vehicles, and space technology through conversational interactions.



🛰️ Mission Explorer



Explore major ISRO missions, understand their objectives, and discover information about satellites, payloads, and mission components.



🚀 Mission Simulator



Experience interactive rocket launch and mission simulations to understand important aspects of space missions.



📊 AI Diagram Generator



Generate visual diagrams that help explain complex space-related concepts and technical information.



🧑‍🚀 AI Personas



Explore space-related personalities through interactive persona-based experiences featuring notable figures from the space community.



🎓 Career Hub



Access information about ISRO career opportunities, examinations, eligibility, and learning resources.

⚙️ Getting Started



Prerequisites



\- Node.js

\- npm



Installation



1\. Clone the repository



git clone https://github.com/SimranKadu/AstraAI.git



2\. Navigate to the project directory



cd AstraAI/ASTRAAI\_V13\_JUSTIFY\_PERSONA\_WIDTH/astraai-v12



3\. Install dependencies



npm install



4\. Configure environment variables



Create a ".env" file and add the required API keys and service credentials. Never commit your actual secrets to GitHub.



5\. Start the development server



npm run dev
